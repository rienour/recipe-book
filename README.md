# Rienour Recipe Book (Rust)

A simple recipe book application, built as a learning project for Rust.

## Purpose

This repository exists to provide a way to practice working with Rust in a project that will have personal real world use. The application will aim to provide ways to work with recipes for a technical user. It will aim to create multiple data formats to create additional projections of the recipes from a basic representation.

Because this is an exploratory project, it is expected:

- Code that may not follow best practices yet
- Frequent changes in structure, design, and approach
- Features that are incomplete or change significantly over time for pre-1.0 versions
- Comments and commit messages that sometimes reflect a learning process rather than a finished product

The primary goal of this project is a personal learning process, however the intent is to transition to a more polished project over time.

## What It Does

The goal of the project is to build a recipe book that can store, organize, and retrieve recipes. Over time, this may include features such as:

- Adding, editing, and removing recipes
- Organizing recipes by category or tags
- Searching recipes by ingredient or name
- Saving and loading recipes from a file or database

The specific features and their implementations are likely to evolve as I learn more about Rust and discover better ways to approach the problem.

## Getting Started

### Prerequisites

You will need Rust and Cargo installed. The easiest way to get both is through [rustup](https://rustup.rs).

### Running the Project

Clone the repository and run it with Cargo:

```bash
git clone https://github.com/rienour/recipe-book.git
cd recipe-book
cargo run -- -h
```

## Project Status

This project is actively evolving and should be considered experimental. Breaking changes, refactors, and rewrites are likely to happen as I continue learning. There is no guarantee of stability or backward compatibility between commits.

## Contributing

Since this is primarily a personal learning project, I am not actively seeking contributions. That said, if you notice something interesting, have suggestions, or want to point out a more idiomatic way of doing something in Rust, feel free to open an issue. I would be happy to learn more from those more experienced; however, please do not provide answers to problems that are not yet considered in the code.
